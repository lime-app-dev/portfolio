Shopify app

Lime Bundles

I built Lime Bundles from scratch as a full-stack Shopify app. I built the embedded admin where merchants configure offers, the storefront widgets shoppers use to assemble bundles, and the discount and cart logic that connects them.

View Shopify App Store listing ↗

What I built

Embedded merchant admin
Built the offer editor with React and TypeScript, and used Shopify’s Admin GraphQL API and Prisma-backed storage to connect merchant settings to Shopify.
Storefront and discounts
Built theme app blocks and shopper-facing widgets, and used Shopify Functions to apply bundle discounts. I also handled the theme editor’s block lifecycle so a new block can render before the merchant saves.
Cross-theme cart integration
Integrated with different cart drawers, checked that each bundle arrived intact, and added recovery for partial adds and a cart-page fallback for unsupported drawers.

Shopify theme

Spread

I built Spread from scratch as a Shopify theme for prepared-meal and food retailers. I developed the storefront, the controls merchants use to configure it, and the product-page interactions that help shoppers choose meals and extras.

In Shopify Theme Store review

What I built

Theme architecture
Built reusable Liquid sections, blocks and JSON templates for the homepage, collections and product pages, with schema settings merchants can configure in Shopify’s theme editor.
Structured product information
Used product metafields and Liquid to render nutrition tables and spice levels. Nutrition rows can include details such as sugars under carbohydrates, with rows drawn from the data each product provides.
Storefront interactions
Used responsive CSS and JavaScript to support meal browsing and build a product-page add-on flow that sends selected extras to the cart alongside the meal.

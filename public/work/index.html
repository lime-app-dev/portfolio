Projects

I brought that experience into two builds of my own. Lime Bundles connects merchant settings to storefront and cart behavior. Spread gives food retailers the tools to build a storefront around their products.

Lime Bundles

Full-stack Shopify app

I built Lime Bundles from scratch as a full-stack Shopify app. I developed the embedded merchant admin with React and TypeScript, integrated Shopify’s Admin GraphQL API and Prisma-backed storage, and built theme app blocks that shoppers use to assemble bundles.

I used Shopify Functions for discounts and built cross-theme cart integration that checks for incomplete adds and falls back to the cart page when a drawer cannot be updated reliably.

Spread

Shopify theme

I built Spread from scratch as a Shopify theme for prepared-meal and food retailers. I developed reusable Liquid sections and blocks, JSON templates and theme editor settings so merchants can configure their storefronts.

I used product metafields to show structured details such as nutrition and spice levels, and built a product-page flow that adds selected meal extras to the cart alongside the main item.
